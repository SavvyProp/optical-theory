# Optical neural networks for autoregressive inference

This theory and simulation project studies optical matrix–vector multiplication (MVM) for feed-forward layers and a recurrent core that updates its state during inference.

The current MLP design reuses one four-wave mixing guide to apply resident Hankel factors. At 128 teeth and 66 passes the modeled electrical cost is 1.47 nJ per block, or 89.6 fJ per local MAC. Eight lanes in three banks cost 34.05 nJ per 1,024-dimensional vector. One simulated 66-factor program gave 42.85% calibrated field error at this energy. Optoelectronic recurrent memory is under consideration. Earlier memory work used the 34-pass Hankel product. A query-independent bias on every pass changes only the output offset. A query-controlled injector can instead select among 34 independently writable 64-component value packets while leaving the factors fixed. The address-supplied simulation checks exact recall and replacement. The two-band frequency-shifting multiplier is retained for comparison. [Bias and addressed-injection analysis](notes/scattering_multipliers.md#adding-a-stored-vector-on-each-pass-of-the-original-product)

For a 1,024-dimensional head, eight lanes can compute one global similarity across a configurable number of cyclic shuffles. Storing the old prediction and its correction as optical factor packets gives a forward-only approximate rewrite when the data returns around the whole stack. A separate test checks the global gradient of the existing local-loop architecture. [Global writes, retention and circuit changes](notes/scattering_multipliers.md#global-writes-with-eight-128-tooth-lanes-and-n-shuffles)

A separate fiber-memory candidate stores 64 columns as wavelength-multiplexed packets. A six-stage time-bin interferometer selects a key, exchanges its predicted value with a new packet, and reuses the same stages to restore the memory. The tested design supports 64 independently writable orthogonal associations and a restricted family of continuous keys. [Recall, retention and energy comparisons with two all-optical write mechanisms](notes/scattering_multipliers.md#exchanging-one-association-in-a-full-matrix)

The multiplication cell must process the comb teeth together in shared optical components and support simple optical backpropagation. A candidate uses one six-stage interleaver for both optical bands. Fixed, short delays applied to one band supply a different Fourier phase pattern in each weight slot. Its ideal finite-packet model implements a dense read, adjoint and write. The modeled identity read reaches +1 dB linear gain with +10 dB after pump rejection and +29.8 dB after the final gate. At 2 pJ a fixed phase on each tooth recovers the equal-input identity to 1.67% deterministic field error. Across 32 random orthogonal programs the error was 6.74–8.18%, while a signed diagonal counterexample gave 83%. [Phase encoding and accuracy limits](notes/scattering_multipliers.md#can-fixed-tooth-phases-recover-the-multiplication). The feed-forward investigation compares recirculating and spatial four-wave mixing (FWM) multipliers with optical amplification. The language-model target uses purely recurrent sequence layers and fiber storage for a writable state that grows quadratically with hidden width. A candidate memory write injects one token-derived optical packet into a scheduled Hankel factor through a coupler with a preset split. RetNet supplies a software benchmark whose dense key–value update requires separately addressed matrix entries in the optical design. HGRN2 supplies a comparison with token-dependent retention. State-expanded Gated DeltaNet provides the large-state recall comparison and Mamba-2 the compact-state comparison. The parallel TTT design sums eight full-band Hankel pairs per 64 × 64 block and updates both factors through one local adjoint per branch. The block stores 2,032 fields. It learned a structured map from 64 writes more accurately than dense delta. In a pretrained TTT language model with frozen outer weights, the calibrated bank gave perplexity 56.4 on 12 WikiText-2 articles, versus 31.9 for a 64 × 32 projected memory and 26.1 for full dense TTT. [Cell and gradients](notes/scattering_multipliers.md#eight-parallel-hankel-pairs-as-recurrent-memory) · [Expressivity, model results and replication](notes/scattering_multipliers.md#how-much-control-does-a-writable-hankel-block-need)

The 34-pass recirculating Hankel bank reached all 4,096 local matrix directions at one signed-real program. After 64 independent associations, ordinary factor-gradient writes retrieved 28% of the stored values in an ideal test, versus 100% for dense delta. Packet reversal supplies the local gradients. Their accuracy as updates to the effective matrix is the limiting issue for a dense recurrent memory. [Viability assessment and reproducible test](notes/scattering_multipliers.md#viability-of-a-34-factor-writable-matrix)

A forward-only write to the newest factor in the 34-pass loop retrieved 39.9% of 32 independent associations in ideal optics. A different encoding stores differences between neighboring matrix entries. In simulation it reproduced dense linear-attention and delta updates using forward visits to the same FWM guide. A 32 × 32 head fits the existing 64 data teeth and needs 32 visits per read or write. Its main hardware requirements are shifting the query band by one tooth on each read visit and delivering the residual and successive key-tooth pairs on each write.
